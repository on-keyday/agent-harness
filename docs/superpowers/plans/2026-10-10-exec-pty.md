# `exec` under a PTY Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An exec can run under a PTY, so `ssh -t host cmd` through the ssh gateway (Zed's remote terminal) and `harness-cli exec -t` get a real terminal.

**Architecture:** A `pty` bit and a `term` string ride `ExecRunRequest` → `RunnerExecRunRequest`; the runner passes `ptyEnabled` to objtrsf and sets `TERM`. Size travels as `TerminalWindowSize` control frames on the existing data stream (first one right after the stream opens). The gateway maps `pty-req`+`exec` onto it and forwards `window-change`; the CLI's `-t` hands the stream to objtrsf's `RemoteShell`. `exec ls` shows `io=pty|pipe`.

**Tech Stack:** Go, brgen `.bgn` schemas (`make protoregen`), objtrsf exec frame protocol, `golang.org/x/crypto/ssh`, bubbletea (TUI), the wasm WebUI.

**Spec:** `docs/superpowers/specs/2026-10-10-exec-pty-design.md`

## Global Constraints

- `pty` is declared AFTER `sshd_parent` in the flag byte; `reserved` shrinks to `:u4`. `term_len :u8` + `term` are appended after the flag byte. `ExecRunInfo` appends `pty :u1` + `reserved :u7` after `taps`.
- `term`: empty = no override; otherwise 1–255 bytes, each in `0x21..0x7e`. One validator, `protocol.ValidateExecTerm`, used by client and runner.
- Refusals (spec D6): `pty` without stdin; `term` without `pty`; an invalid `term`. A typed option takes effect or errors — never silently ignored.
- No new capability (D5). `exec_run` gates a PTY exec.
- Initial size: both-or-nothing (rows and cols non-zero), as `applyInitialWindowSize`.
- `exec -t`: CLI only (`CmdlineSurfaces: CLI` + `SurfaceReason`); refuses a non-terminal stdin before dialing; Ctrl+] ends the exec (D8).
- The gateway's PTY exec does NOT intercept Ctrl+] (D9).
- Repo is public: no LAN IPs, hostnames or private paths in committed files.
- Verify with make targets (`make test`, `make check`, `make wasm-check`, `make test-integration`), not ad-hoc `go build`.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **`window-change` that arrives before the exec's stream is open** — the gateway must not drop it; the last size sent wins. Pinned by `TestExecResizerKeepsTheLastSizeUntilSet` (Task 5).
2. **The ssh client's stdin ends while a PTY exec runs** (`ssh -t host cmd < /dev/null`) — the child is hung up and the exec ENDS with an outcome; it must not hang. Pinned by `pty_stdin_eof_ends_the_exec` (Task 4).
3. **A `TERM` the client sent that fails validation** (a space, a control byte) — refused with a message naming the rule, not run with a mangled environment. Pinned by `TestValidateExecTerm` (Task 1) and `TestExecRunRefusesAnInvalidTerm` (Task 3).
4. **`pty-req` with a zero size** — no initial frame is sent and the exec still runs (at 0×0, which is measured as harmless in practice). Pinned by `TestExecRunSendsNoInitialSizeWhenHalfIsZero` (Task 3).
5. **A NEW runner meeting an OLD server, and the reverse** — the skew must be recoverable. Pinned by `scripts/wire-skew-check.sh` (Task 8).

```go
package protocol

import "fmt"

// ValidateExecTerm checks the TERM an exec request carries (ExecRunRequest.term).
// Empty is valid and means "leave TERM alone".
//
// The value becomes ONE environment variable in the child, so the alphabet is
// printable non-space ASCII: no byte a terminfo lookup, a shell or an env block
// would read as a separator. The client checks before sending and the runner
// checks again before running — the runner is the party that applies it.
func ValidateExecTerm(term string) error {
	if len(term) > 255 {
		return fmt.Errorf("term is %d bytes, at most 255", len(term))
	}
	for i := 0; i < len(term); i++ {
		if c := term[i]; c < 0x21 || c > 0x7e {
			return fmt.Errorf("term %q: byte %#x at %d is not printable non-space ASCII", term, c, i)
		}
	}
	return nil
}
```

```go
//go:build !js

package sshgw

import "sync"

// execTTY is what a pty-req asked for, carried to the exec that follows it.
type execTTY struct {
	term string
	dims ptyDims
}

// execResizer hands window-change to a PTY exec whose stream may not be open
// yet. Until set, the last size is kept; set applies it, so whichever arrives
// first, the exec ends up at the size the client last reported.
type execResizer struct {
	mu   sync.Mutex
	fn   func(rows, cols, widthPx, heightPx uint16) error
	last *ptyDims
}

func (r *execResizer) apply(d ptyDims) {
	r.mu.Lock()
	defer r.mu.Unlock()
	if r.fn == nil {
		r.last = &d
		return
	}
	// A resize the stream cannot take means the stream is gone, and the exec's
	// own end reports that; there is nothing more to say from here.
	_ = r.fn(d.Rows, d.Cols, d.WidthPx, d.HeightPx)
}

func (r *execResizer) set(fn func(rows, cols, widthPx, heightPx uint16) error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	r.fn = fn
	if r.last != nil {
		_ = fn(r.last.Rows, r.last.Cols, r.last.WidthPx, r.last.HeightPx)
		r.last = nil
	}
}
```

```go
func readUntilContains(t *testing.T, r io.Reader, want string, d time.Duration) string {
```
