# Overview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One summary screen — needs you / tasks / hosts / forwards / board — on the CLI (`overview`), the TUI (an overlay) and the WebUI (a 概要 tab), computed once in Go.

**Architecture:** A pure `cli.BuildOverview` turns runners, tasks, conns, forwards and board topic rows (+ the newest message of the first K topics) into an `Overview` value. The CLI fetches all inputs through one `*cli.Client` helper; the TUI and the wasm bridge reuse what they already hold and fetch only what they lack. Every surface prints the `Overview` as given.

**Tech Stack:** Go (cli, bubbletea TUI, js/wasm bridge), vanilla JS WebUI, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-17-overview-design.md`

## Global Constraints

- No wire / `.bgn` change.
- Run Go tests with the Makefile's env scrub: `make test`, or for one package `env -u HARNESS_AUTH_TICKET -u HARNESS_TASK_ID -u HARNESS_RUNNER_ID -u HARNESS_SERVER_CID -u HARNESS_SERVER_PUBKEY -u HARNESS_SERVER_PUBKEY_FILE -u HARNESS_WS_PATH -u HARNESS_PROXY_VIA_RUNNER go test ./<pkg>/ -run <Name>` (written `$SCRUB go test …` below).
- Compile checks write no binary: `go build ./...`, `GOOS=js GOARCH=wasm go build -o /dev/null ./cmd/harness-webui-wasm`.
- No surface restates a rule: "needs you" is `cli.stateGroup`, activity is `cli.TaskActivityAt`, now-text is `cli.TaskNowText`, runner words are `cli.RunnerStatusWord`.
- Agent-written text: task text through `vtgrid.SanitizeTitle`; board head through `cli.EscapeForTerminal`; WebUI writes only via `textContent`.
- Empty sections print their zero count, never elided.
- Constants (in `cli/overview.go`): `OverviewRowCap = 3` (rows per section), `OverviewHeadRunes = 60`.
- Verb surface work follows the `conns` entry (`cli/verb/table.go:2071`) and must walk the `surface-parity-checklist` skill item by item before Task 6 is reported done.
- Commit on the current `harness/<dir>` branch, staging explicit paths only.

## Review Focus

1. A board payload with ESC / C1 bytes or invalid UTF-8 → head prints `\xNN`, never raw (Task 3 test `TestBoardHeadEscapes`).
2. A prompt with `\x1b[2J` in the TUI About column and in the overview → bytes dropped (Task 1 test `TestTaskNowTextSanitisesPrompt`).
3. An agent caller without the conns / forwards / board cap → the other sections still render and the failed one names its error (Task 4 test `TestOverviewWithPartialFailure`).
4. A topic deleted between `BoardTopics` and its head read (not-found) → row without head, no error (Task 3 test `TestBuildOverviewBoardHeadMissing`).
5. The overlay / tab closed while a fetch is in flight → late result ignored, no poll keeps running (Task 5 test `TestOverviewPollStopsOnClose`; Task 6 checks `document.body.dataset.activeTab` before fetching).

```go
func TaskStateGroup(t protocol.TaskInfo) string // = stateGroup; stateGroup stays as its body

type OverviewInput struct {
	Runners     []protocol.RunnerInfo
	Tasks       []protocol.TaskInfo
	Conns       []protocol.ConnInfo
	ConnsErr    error
	Forwards    []protocol.PortForwardInfo
	ForwardsErr error
	Topics      []BoardTopicRow
	TopicsErr   error
	Newest      map[string]*BoardMessage // topic → newest message; nil/absent = no head
}

type OverviewTask struct {
	ID, Repo, Badge, Now, Group string
	ActivityAt              int64
}
type OverviewHost struct {
	Hostname, Goos             string
	Idle, Busy, Offline        int
	ActiveTasks, MaxTasks      int
}
type OverviewForward struct {
	ID                uint64
	Dir, Spec, TaskID, Repo string
}
type OverviewTopic struct {
	Name          string
	MsgCount      int
	LastPublishMs uint64
	Head          string // "" when unknown; "(withdrawn)" when the newest is retracted
}
type Overview struct {
	NeedsYou      []OverviewTask; NeedsYouCount int
	Live          []OverviewTask
	GroupCounts   map[string]int // ready / working / no report / queued / finished, zeros present
	Hosts         []OverviewHost; HostCount, SlotCount, OperatorClients int; HostsErr string
	Forwards      []OverviewForward; ForwardCount int; ForwardsErr string
	Topics        []OverviewTopic; TopicCount, MsgTotal int; BoardErr string
}

func BuildOverview(in OverviewInput, now time.Time) Overview
func BoardHead(m *BoardMessage) string
func OverviewHeadTopics(topics []BoardTopicRow) []string // the first OverviewRowCap names by LastPublishedAtMs desc, name asc on ties
```

Rules `BuildOverview` must hold (each one a test case):
- `NeedsYou` = live tasks with `TaskStateGroup == "needs you"`, by `TaskActivityAt` desc, capped at `OverviewRowCap`; `NeedsYouCount` uncapped.
- `Live` = other non-terminal tasks, same order and cap. `GroupCounts` has every key of `stateGroupOrder` except `needs you`, zero included.
- `Badge` = `LifecycleBadge(&t)` (`cli/lifecycle.go:100`), else `ProgramBadge(&t)` (`cli/lifecycle.go:182`); `Repo` = last path element of `RepoPath`.
- `Hosts`: one per `Hostname`, sorted by name; `SlotCount` = runners; `OperatorClients` = conns with role Cli/Tui/Webui; `HostsErr` = `ConnsErr` text (hosts still listed).
- `Forwards`: by `LastActivityUnixMs` desc, capped; `Repo` from the owning task in `Tasks` ("" if not listed).
- `Topics`: by `LastPublishedAtMs` desc (name asc on ties), capped; `MsgTotal` sums all topics; `Head` = `BoardHead(Newest[name])`.
- `BoardHead`: payload's first line (cut at `\n`), at most `OverviewHeadRunes` runes, then `EscapeForTerminal`; `Retracted` → `"(withdrawn)"`; nil → `""`.
